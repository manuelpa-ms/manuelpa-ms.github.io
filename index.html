Selected work / full-stack systems

Flagship project · Designed, built & operated solo

Galactic Gambit

A real-time, mobile-first space-strategy MMO. A persistent shared galaxy, fleets, alliances, and seasonal competition, taken from alpha to public beta with real players and live seasons.

One ruleset, both sides

Pure deterministic domain logic is shared between server and client, keeping player previews aligned with authoritative server decisions.

Simulation as a development tool

CLIs simulate bot empires through a full season. HTML balance reports compare progression, combat, and onboarding against saved baselines, alongside feedback from live play.

Tests beyond the happy path

Approximately 300 test files span unit, fast-check property-based, integration, and balance testing, plus Playwright end-to-end checks against the release build.

Built to operate and iterate

Azure Bicep/cloud-init provisioning, Caddy, Litestream replication to Azure Blob, scripted deploys and restores, and a load harness. Email, Google, and Discord sign-in, an optional Supporter subscription, and a player guide round out the product.
